Version 0.1.1 · field preview · July 31, 2026

Mapper Faster with Map Hub

This is the current COC product build: the faster renderer, tiled and network imagery, native Map Hub imagery in its supplied CRS, browsing, read-only opening, edit requests, and connected editing. Mobile builds also include the current field GNSS and sketching work.

  • macOS — Apple silicon disk image (.dmg)
  • Windows x64 portable build (.zip)
  • Linux x86-64 portable archive (.tar.gz)
  • Android arm64 preview (.apk)
  • Release details and build provenance
  1. Install the package for your platform.
  2. Open Mapper and click Map Hub.
  3. Choose Connect an existing account and approve the connection in your browser. Map Hub uses its normal passkey sign-in.

The macOS and Windows preview packages are unsigned. The macOS app is internally sealed and verified, but not Apple-notarized: Control-click Mapper, choose Open, then confirm Open. If macOS still blocks it, use System Settings > Privacy & Security > Open Anyway. In Microsoft Defender SmartScreen, select More info, then Run anyway.

The Android APK is preview-signed for direct installation rather than Play Store distribution. Uninstall an older preview first if Android reports a signing conflict.

Version 0.9.7-COC.5 · corrected packaging July 30, 2026

Mapper Core (COC Base)

This upstream-faithful build adds online satellite/aerial imagery and importable imagery catalogs. It does not include Map Hub.

  • macOS — Apple silicon disk image (.dmg)
  • Windows x64 installer (.exe)
  • Windows x64 portable build (.zip)
  • Linux x86-64 portable AppImage
  • Linux x86-64 Debian/Ubuntu package (.deb)
  • Linux x86-64 RPM package (.rpm)
  • Linux x86-64 Flatpak bundle
  • Android arm64 preview (.apk)
  • Release manifest (.json)
  • Puget Sound imagery catalog (.oic)

The macOS and Windows preview packages are unsigned. The macOS app is internally sealed and verified, but not Apple-notarized: Control-click Mapper, choose Open, then confirm Open. If macOS still blocks it, use System Settings > Privacy & Security > Open Anyway. In Microsoft Defender SmartScreen, select More info, then Run anyway.

The Android APK is preview-signed for direct installation rather than Play Store distribution. Uninstall an older COC preview first if Android reports a signing conflict.

  1. Open Templates > Online Imagery.
  2. Paste a tile URL or import the puget-sound.oic catalog.
